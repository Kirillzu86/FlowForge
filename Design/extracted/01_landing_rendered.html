Всё для автоматизации в одном месте

Визуальный редактор

Холст React Flow: зум, миникарта, Undo/Redo и автосохранение.

Единый AI-адаптер

Более 100 моделей через LiteLLM: GPT-4o, Claude, Gemini и локальная Ollama.

Асинхронное ядро

Celery и Redis обходят граф, ловят циклы и запускают независимые ветки параллельно.

Мониторинг в реальном времени

SSE подсвечивает ноды и связи, а консоль показывает входы и выходы каждого шага.

Гибкая логика

Условия, HTTP-запросы и изолированный Python-код в одном сценарии.

Готов к продакшену

Docker Compose, Nginx, автодеплой в Coolify и SSL Let’s Encrypt.

Быстрый старт за три команды

Нужны только Docker и Git. Редактор откроется на localhost:5173.

git clone your-username/flowforge
cp .env.example .env
docker compose up --build -d
